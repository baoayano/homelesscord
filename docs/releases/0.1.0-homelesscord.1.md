# Homelesscord 0.1.0-homelesscord.1

This is the first Homelesscord alpha prerelease. It retains Meowcord's upstream history and adds the downstream development workflow and free evolving Nitro profile badges.

Every ordinary account starts with a Nitro badge. It advances at 1, 3, 6, 12, 24, 36, 60 and 72 completed UTC calendar months. Staff appears first, Nitro follows it, and the remaining custom and Pride badges keep their relative order. Accounts without Staff show Nitro first.

The start date is `registration_date`, defaulting to the exact account creation time. Operators can change **Nitro registration date** in the admin panel or clear it to reset it to account creation. PostgreSQL and SQLite migrations backfill existing accounts and preserve dates already customized. Ordinary profile changes cannot edit the date.

Nitro badges use the original pinned local PNG artwork. The required Equicord plugin renders the native tooltip card with its tier title, large artwork and formatted Nitro registration day. Hover and keyboard focus open the card. Clicking does not open subscription dialogs. The broader Discord badge discovery experiment stays unchanged. Pride selection and all existing free Premium capabilities remain available.

The reviewed client remains Discord build 633029 and Equicord commit `1489c0e2a4435d854d7343a5cfb0abb894772318`. The source archive excludes cached Discord code, compiled Equicord assets, runtime configuration, credentials and databases. Follow the existing setup instructions to generate client assets. Existing installations must rebuild the server and Equicord, then restart the server to apply migrations. Back up the database before updating.

Source build, server and encryption typechecking, lint, badge and date tests, PostgreSQL and SQLite migration fixtures, the Equicord patch checker and isolated API parity checks passed with 151 passes, 1 provider skip and 0 failures. Native tooltip browser checks cover default, Silver and Opal badges in DM and expanded profiles, keyboard focus and clicks. Profile tests cover Staff priority with edited Staff artwork, a shuffled database result and preserved custom and Pride badges.

The local full unit suite has 1099 passing tests, 60 skips and the same 26 existing failures: 25 unavailable WebKit cases and the upstream native reply fixture. The optional Equicord typecheck retains the upstream `webScreenShare.browser` TS2774 diagnostic, also reproduced without the new plugin. This prerelease remains unstable and unofficial; publishing it does not deploy a production instance.

See [Nitro badges](../features/nitro-badge-assets.md) for date semantics and tooltip experiment details, and [downstream development](../development/downstream.md) for upstream updates.
