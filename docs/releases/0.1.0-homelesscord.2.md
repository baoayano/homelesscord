# Homelesscord 0.1.0-homelesscord.2

This alpha prerelease adds native badge management and merges ten commits from Meowcord through `c298981`. It includes upstream instance Automod, invite-only registration, join reasons, stronger Cap challenges, account IP administration and bulk account removal.

Open User Settings, Profiles, Your badges to view badge details and customize their order. Every visible badge can be reordered, including Staff and the free evolving Nitro badge. Staff starts first and Nitro second until an account saves a different order. Staff can be hidden; Nitro hiding depends on the account's server-assigned badge management treatment. Selected Pride badges remain visible. Firefox and Chromium use pointer and keyboard dragging, with a preview, insertion line, cancellation, Save and Reset.

The directory shows Nitro tiers, registration date and progression alongside assigned badge descriptions and known rarity. Badge settings apply to global and guild profiles. The badge management database migration preserves existing accounts, and the new upstream migrations add account IPs, Automod actions and instance invites to both PostgreSQL and SQLite.

This release keeps Discord client build 633029 and Equicord commit `1489c0e2a4435d854d7343a5cfb0abb894772318`. The source archive excludes cached Discord code and generated Equicord output. Rebuild the server and Equicord, then restart to apply migrations. Back up the database before updating a persistent instance. Publishing this source release does not deploy an instance.

Validation on an isolated PostgreSQL instance passed the source build, typecheck, lint, client patch checker, API parity with 151 passes and one unconfigured provider skip, and the complete E2EE browser check. Firefox verified separate Staff and Nitro drags with saved order after reopening the editor. Chromium verified dragging and saving with only the existing `program-rewards` 404 from the client. The full unit suite has 1,163 passes, 61 skips and 25 WebKit checks unavailable in this environment.
